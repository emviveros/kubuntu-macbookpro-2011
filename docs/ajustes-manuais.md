# Ajustes manuais dentro dos apps

Itens que não dá para configurar pelo sistema ou que não foram automatizados.

## Firefox

- Em `about:config`, defina `browser.compactmode.show = true`. Depois vá em *Menu → Mais ferramentas → Personalizar barra de ferramentas → Densidade → Compacta*.
- Opcional: `layout.css.devPixelsPerPx = 0.9` reduz tudo. Com o DPI 88 o Firefox já fica uns 8% menor, então teste antes.

## Konsole

- `Ctrl+Shift+M` esconde a barra de menus.
- Em *Configurações → Barras de ferramentas mostradas*, dá para desmarcar as barras.

## Apps KDE em geral

- `Ctrl+M` esconde a barra de menus. Com o Menu global, ela já aparece na barra superior.
- Barras de ferramentas: botão direito → *Posição do texto → Somente ícones*.

## Dolphin

- `Ctrl+-` / `Ctrl++` ajustam o zoom da pasta atual.
- Em *Configurações*, dá para desmarcar *Mostrar barra de ferramentas*.
